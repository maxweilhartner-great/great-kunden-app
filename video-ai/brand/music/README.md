# Hintergrundmusik

Hier lizenzfreie Musikstücke ablegen (`.mp3`, `.m4a`, `.wav`, `.ogg`, `.flac`).
Die App wählt pro Reel zufällig ein Stück aus; in der Freigabe kann ein bestimmtes Stück
oder „Keine Musik“ gewählt werden. Spricht jemand im Video, wird die Musik automatisch leiser.

Wichtig: Nur Musik verwenden, die für Social Media **kommerziell** genutzt werden darf, z. B.

- YouTube Audio Library (Lizenz „keine Namensnennung erforderlich“)
- Pixabay Music
- eigene, gekaufte Lizenzen

Musik aus Charts/Streaming-Diensten führt zu Sperren oder stummgeschalteten Videos.
